# Parapara Animator

Python / Qt ベースの簡易パラパラアニメ制作ツールです。画像をドラッグ＆ドロップで読み込み、順番と表示時間を設定してアニメーションを再生できます。

## 主要機能
- jpg / png / webp など一般的な画像を複数回に分けてドラッグ＆ドロップで読み込み
- 1枚のスプライトシートを、指定した縦（行）×横（列）の枚数でフレームに分割
- 読み込んだフレームを、任意の縦（行）×横（列）のスプライトシートとして保存
- 画像ごとに待ち時間（ミリ秒）を編集可能
- 「上へ」「下へ」ボタンで再生順の入れ替え
- Start / Stop ボタンによる再生制御、ループ再生の ON / OFF
- 停止中のみ動作する「コマ送り」ボタン（ループ設定に追従）
- 選択中のエントリを `Delete` キーで削除
- 表示領域では画像の中心を基準に描画

## 依存関係
```
pip install -r requirements.txt
```

## 使い方
1. `python main.py` でアプリを起動します。
2. スプライトシートを使う場合は、読み込む前に「読み込み時の分割」で縦（行）と横（列）の枚数を指定します。通常の画像は `1 × 1` のまま読み込みます。
3. 一覧リストに画像ファイルをドラッグ＆ドロップします。追加直後は 200ms の待ち時間が設定されます。
4. 待ち時間はリスト右列を直接編集して変更できます。
5. 順番を変えたい画像を選択し、「上へ」「下へ」ボタンで移動させます。
6. Start で再生、Stop で停止します。停止中は「コマ送り」で 1 フレーム先に進められます。
7. スプライトシートとして出力する場合は、「シート出力」の縦（行）と横（列）を指定して「保存」を押します。
8. Delete キーで選択中のエントリを削除できます。

## 補足
- ループが OFF の場合、最後の画像まで再生すると自動的に停止します。
- ループが ON の場合、最初の画像に戻って繰り返し再生します。
- スプライトシートは左上から右へ進み、行の末尾まで進むと次の行の左端へ移る順序で再生します。たとえば `縦 2 × 横 5` は 10 フレームになります。
- 出力枠がフレーム数より多い場合、残りの枠は透明で合成されます（JPEG 保存時は透過されません）。フレームの大きさが異なる場合は、最大サイズの枠内で中央揃えにします。
- 再生中に並び替えや削除を行うと再生が停止します。必要に応じて再度 Start を押してください。
